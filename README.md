# portfolio-optimization
Equity Portfolio Optimization with Python:

<ul>Developed a comprehensive stock portfolio analysis and optimization tool using Python. Utilized libraries such as pandas for data manipulation, yfinance for data acquisition, and matplotlib and plotly for data visualization</ul>
<ul>Implemented Monte Carlo simulations and the Markowitz Efficient Frontier for portfolio optimization. Conducted extensive simulations to explore portfolio allocations, calculated the Sharpe Ratio to evaluate performance, and identified optimal portfolio weights that maximize returns and minimize risk</ul>
